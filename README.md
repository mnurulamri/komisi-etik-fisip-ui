# Aplikasi Pengajuan Etika Penelitian FISIP UI

## Deskripsi

Aplikasi Pengajuan Etika Penelitian FISIP UI merupakan sistem berbasis web yang dikembangkan untuk mendukung proses pengajuan, pemeriksaan administratif, review, revisi, monitoring status, hingga penerbitan surat keterangan lolos etik penelitian secara digital dan terintegrasi.

Sistem ini dikembangkan untuk mendukung operasional Komisi Etik FISIP UI dalam mengelola proses evaluasi etik penelitian secara lebih efektif, terstruktur, dan terdokumentasi.

---

# Fitur Utama

## Autentikasi Pengguna

* Login menggunakan SSO UI
* Login pengguna non-UI
* Manajemen akun pengguna

## Pengajuan Protokol Penelitian

* Input data penelitian
* Input anggota peneliti
* Upload dokumen pendukung
* Pengisian pertanyaan etik

## Monitoring Pengajuan

* Tracking status pengajuan
* Dashboard indikator proses review
* Histori catatan reviewer

## Review dan Revisi

* Pemberian catatan reviewer
* Revisi dokumen penelitian
* Validasi administratif

## Generate Dokumen

* Generate surat keterangan lolos etik
* Export dokumen PDF menggunakan TCPDF

# Arsitektur Sistem

Sistem dikembangkan menggunakan arsitektur MVC (Model-View-Controller) dengan framework CodeIgniter 3.

Komponen utama:

* Frontend berbasis HTML, CSS, dan jQuery
* Backend menggunakan PHP dan CodeIgniter 3
* Database MariaDB
* Web server NGINX
* Library TCPDF untuk generate sertifikat PDF

---

# Role Pengguna

| Role         | Fungsi                                     |
| ------------ | ------------------------------------------ |
| Pengaju      | Mengajukan penelitian dan melakukan revisi |
| Sekretariat  | Melakukan pemeriksaan administratif        |
| Reviewer     | Melakukan review etik penelitian           |
| Ketua Komite | Memberikan keputusan akhir                 |

---

# Alur Sistem

1. Pengguna melakukan login
2. Pengguna membuat pengajuan penelitian
3. Sekretariat melakukan verifikasi administratif
4. Ketua komite melakukan penugasan reviewer
5. Reviewer memberikan evaluasi dan catatan
6. Pengaju melakukan revisi jika diperlukan
7. Ketua komite memberikan keputusan akhir
8. Sistem menghasilkan surat keterangan lolos etik
